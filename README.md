# OWL 手机版 · 游戏本体托管

这个仓库只做一件事：**托管 WorldBox 的官方原版 APK**，给 OWL 手机版当下载源。

- 不含任何注入、不改游戏内容
- 下载后由 OWL 在设备本地完成注入（改清单 + 加桥接 dex + 重新签名）

## 版本

| 版本 | ABI | 大小 | 模组支持 |
|---|---|---|---|
| 0.51.4 | arm64-v8a | 167.8 MB | 支持（内置 NeoModLoader）|
| 0.50.5 | arm64-v8a | 165.0 MB | 不支持 |
| 0.22.20 | arm64-v8a | 120.8 MB | 不支持 |
| 0.14.5 | arm64-v8a | 54.1 MB | 不支持 |

安装包在 [Releases](../../releases) 里。

## 注意

如果手机上已经装了官方签名版，装 OWL 注入版前必须先卸载（签名不同），
卸载会清空存档。
